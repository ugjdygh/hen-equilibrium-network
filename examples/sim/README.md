## 当前输出里的两个结论（2026-11-22）

1. **收敛式发行可把稳态期年增量压在 0.3%–1.0% 区间内**：`g(t) = 0.5% + 7.5%·exp(-t/8)`，第 25 年起全部低于 1%。代价是启动期（前 10 年）明显高于稳态区间，且总量无上限——这正是 Q4 要回答的事。
2. **"连续同向调整 3 次即熔断"与幅度需求冲突**：算力跃升 1.8× 需要一轮累计 +80% 的调整，但连续 3 次上调就触发冻结，末态只到 13.3/18.0，**未收敛**。初步结论：熔断不应以"连续次数"为条件，应改为"累计幅度 + 时间窗"，或冻结后仅暂停并降增益。

这两条都是**玩具模型的结论**，目的是暴露问题，不是证明方案。它们已被记录到 `docs/research/open-questions.md` Q4 / Q6。

## 你可以直接反驳的四个点

1. 收敛式发行的时间常数 τ=8 年，是不是只是把"温和通胀"换了个说法？
2. 保底 0.5% 是主观取值；若改为 0.2%，安全预算是否还够（Q4）？
3. 难度闭环里算力是阶跃而非连续变化；连续漂移下会不会更好或更糟？
4. 手续费分流假设总量恒定，真实的手术费随活跃度波动，恒等式仍然成立但激励会剧烈起落。
