# 社区实现登记 / Community Implementations

本目录**只放说明，不放代码**。

目的：记录"有哪些独立实现在做这件事"，同时避免主仓库出现"官方实现"的错觉（`docs/ecosystem/implementations.md`）。

## 规则

1. 主仓库不接收任何实现代码作为"官方版本"。
2. 想登记你的实现：在 `docs/ecosystem/implementations.md` 提 PR，说明与本规范的差异与审计状态。
3. 若确实需要在本目录留一个入口，请只放一个 `README.md` 或链接说明，不复制代码。
4. 实现方自行负责安全；未审计须自标"未审计"。

## 提醒

从零实现一个账本节点的常见死法（按发生频率）：

1. 把"条件失败"实现成"超时后任何人可取"；
2. 把"未定义标志位"实现成"忽略"；
3. 难度调节忽略测量延迟，仿真稳、实网震荡；
4. 交易池与共识各自维护一份"合法交易"定义，久了就不一致；
5. 双花检查在并发下漏检。

对应用例：`docs/handover/test-cases.md` TC-SC-06、TC-BH-06、TC-DA-05、TC-MP-03。
