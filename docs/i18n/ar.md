مستودع بحثي عام حول دفتر أستاذ لامركزي افتراضي: تداول مستقر، شبكة نظير لنظير متعددة الطبقات، كلفة طاقة محدودة، خصوصية قابلة للضبط، وتطوّر قابل للتراجع.

- **ما هذا**: وثائق بحثية — صياغة المشكلة، مسوّدات البروتوكول، أسئلة مفتوحة، ومواد للتسليم.
- **ما ليس هذا**: لا إصدار أي أصل، لا جمع تمويل، لا شبكة قيد التشغيل، ولا أي وعد بإطلاق أو قيمة.
- **الحالة**: وثائق فقط. الورقة البيضاء غير نهائية، ولا يوجد تنفيذ.
- **المؤلف**: Lee Hyun seok (이 현석) — اسم مستعار بحثي.
