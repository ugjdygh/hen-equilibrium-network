# Name clearance — findings and decision

Date of search: 2026-11-23. Scope: Chinese name, English name, abbreviation; classes 9, 35, 42.
Method: open web and register-derived sources (CNIPA-linked databases via public aggregators, USPTO publication records, GitHub search). **This is a screening search, not a legal opinion and not a register search by an agent.** Absence of a hit here is not evidence that no right exists.

---

## 1. Findings

### 1.1 Chinese name 衡远网络 / 衡远

| Mark | Holder | Classes | Status | Bearing on this project |
|---|---|---|---|---|
| 中船衡远 | China Shipbuilding Heavy Industry Group Hengyuan Technology | **09, 35, 42** (+06, 07, 11, 12) | Registered, filed 2022-04-15 | Occupies **all three classes requested** |
| 衡远 | Zhejiang Geely Holding Group | 09 (signal, telecom, measuring, electric components, batteries) | Registered, 2021-09-21 to 2031-09-20 | Blocks class 9 independently |
| 杭州衡远网络科技有限公司 | (company, Hangzhou) | — | Company name in use, network technology services | The exact phrase is a live company name |

Conclusion: **the Chinese name is not available in classes 9, 35 or 42.** Filing would be refused or opposed, and use in commerce in those classes creates a real conflict.

### 1.2 English name Horizon Equilibrium Network

No registration or use of the full phrase was found. The word *Horizon* alone is heavily used (a TMS medical device "Magstim Horizon", "Horizon Chemical", agencies and projects named Horizon), which makes the phrase distinctive only **as a whole**. GitHub exact-phrase search at repository creation returned 0.

Conclusion: usable as a source identifier; protectable, if at all, only as the full four-word phrase — never as "Horizon" or "Horizon Network".

### 1.3 Abbreviation HEN

Multiple live or pending marks containing HEN were found, including **HEN HOODIE** (USPTO, class 9, pending), HEN & BULL (class 43), HEN, HEARTH AND HOME (class 4), Henjda (UK, class 20). A three-letter string of this kind is weak, crowded and expensive to enforce.

Conclusion: **HEN is not registrable as a mark and must never be the sole designation.** Always write the full name first; use the abbreviation only after it has been introduced.

---

## 2. Class 35: decided against filing

Class 35 covers advertising, business management and office services. This project offers none of them, and has no plan to. Filing in class 35 would (a) declare a commercial service that does not exist, (b) put the project in the same class as 中船衡远, and (c) contradict the boundary that nothing here is a business. **Deferred indefinitely.**

## 3. Decision (effective 2026-11-23)

1. **English full name is the only brand-level designation**: `Horizon Equilibrium Network (HEN)`. It identifies the source of the documents and nothing more.
2. **The Chinese name is demoted to a literal translation.** It appears as 衡远网络（意译）in the Chinese edition and is **not** used as a brand, a trade name, a domain, an account name or a filing basis. It carries no rights claim.
3. **No trademark application now**, and none in class 35 later. If a prototype stage ever begins, the filing (if any) is the full English phrase in **classes 9 and 42 only**, after a paid register search.
4. **If Chinese registration is ever needed**, the starting point must be a coined name that does not contain 衡远 and does not paraphrase 衡远网络; that name must clear classes 9/35/42 first. No such name is proposed here, to avoid creating an uncleared suggestion.
5. **Abbreviation discipline**: full name first, abbreviation in parentheses; no product, token, venue, wallet or sub-brand may carry the abbreviation alone.
6. **Conflict policy unchanged**: on an assertion of prior rights, rename; do not litigate; record the old name in `CHANGELOG.md`.
